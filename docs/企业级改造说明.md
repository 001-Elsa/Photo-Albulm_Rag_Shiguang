# 工程化与企业模式说明

本仓库同时包含：

1. **Personal Mode**：单机多模态检索，适合本地相册和算法主线。
2. **Enterprise Mode**：PostgreSQL/pgvector、Redis、Celery、MinIO、多租户与观测基线。

不要把“已具备可运行企业骨架”写成“已完成生产级媒资平台”。

## 已落地

### Personal Mode

- SQLite 业务库、本地缩略图、NumPy 向量检索
- 可选旁路 `PgVectorStore`（实验性）
- 进程内可靠索引任务状态机
- OCR 中文 n-gram、人脸聚类与人物命名（个人模式）
- Argon2id 认证、RBAC、审计、限流、Prometheus 文本指标

### Enterprise Mode

- Organization / Collection / Asset / Job / Embedding / OCR / Face
- PostgreSQL RLS 租户隔离 + Collection ACL
- 独立 Migration 进程：管理员账号建表，应用账号 `NOBYPASSRLS`
- MinIO 对象存储与预签名下载
- Celery Worker / Beat：缩略图、向量、OCR、人脸；心跳回收、补投、死信
- Redis 会话、限流、队列深度
- Explainable Reranker（默认人工权重，可加载训练 JSON）
- Prometheus / Grafana / OpenTelemetry Collector

```bash
curl http://127.0.0.1:8626/readyz
```

## 简历建议话术

可用：

> - 设计 Personal / Enterprise 双模式：单机 SQLite 检索链路，与 FastAPI + Celery + Redis + PostgreSQL/pgvector + MinIO 企业骨架
> - 实现组织级 RLS、Collection ACL、可靠索引任务状态机、死信与心跳回收
> - 实现可解释线性精排器，并预留标注特征训练脚本；指标以真实评测为准

不要写：

> - 已完成生产级多租户媒资平台
> - Recall@5 达到 86% / P95 低于 100ms / 支持十万级图片（除非提交真实报告）
> - 已训练学习排序模型（当前默认是人工权重）
> - 完整人物检索系统（企业模式尚未闭环）
