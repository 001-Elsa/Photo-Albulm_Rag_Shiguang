# 安装运行指南(Windows)

按你的机器习惯:所有环境和模型都装在 **D 盘**,先检查有没有现成的再下载。

## 一、准备 Python 环境

先检查:命令行输入 `python --version`,3.9 以上即可,没有再去 python.org 装(安装路径选 D 盘)。

```bat
:: 建虚拟环境到 D 盘(start.bat 会自动优先使用这个路径)
python -m venv D:\envs\shiguang
D:\envs\shiguang\Scripts\activate
```

## 二、安装依赖(由轻到重,装一步就能跑一步)

```bat
:: 1. 核心(必装,几十 MB):启动服务、扫描、缩略图、检索框架
pip install -r requirements.txt

:: 2. 语义模型(推荐；实际体积以当前依赖和模型版本为准)
pip install torch transformers
:: 模型权重想放 D 盘:先设环境变量 HF_HOME=D:\hf_cache 再启动
:: 首次下载时显式允许联网；下载完成后可恢复为 false
set SHIGUANG_MODEL_DOWNLOAD_ENABLED=true

:: 3. 可选:截图文字搜索(约 60MB)
pip install rapidocr-onnxruntime

:: 4. 可选:人脸("和某人的合影")
pip install insightface onnxruntime
:: 人脸模型想放 D 盘:设环境变量 INSIGHTFACE_HOME=D:\insightface

:: 5. 可选:iPhone HEIC 格式
pip install pillow-heif
```

> 一个包都不装模型也能启动——会用 demo 伪向量后端跑通全流程,但检索没有语义,
> 界面设置页会有黄色警告。装好第 2 步后重启即可。

## 三、启动

```bat
:: 双击 start.bat,或:
D:\envs\shiguang\Scripts\python.exe run.py
```

浏览器打开 `http://127.0.0.1:8626`:

1. **设置** → 相册目录填入如 `D:\Photos`(每行一个)→ 保存目录
2. 点 **开始/继续索引**,看进度条(扫描 → 向量化 → OCR → 人脸)
3. 中途可以直接关掉,下次点同一个按钮从断点继续
4. 索引完成后回到 **检索** 页开搜

## 四、进阶

### ONNX int8 量化(CPU 提速、省内存)

```bat
pip install onnx onnxruntime
python scripts\export_onnx.py --int8
:: 重启后设置页"模型后端"显示 onnx 即生效(自动优先加载 int8)
```

### 本地大模型查询解析(可选)

规则解析已覆盖常见说法;想要更聪明的解析,装 [Ollama](https://ollama.com)(装到 D 盘),然后:

```bat
ollama pull qwen2.5:3b
```

把 `data/config.json` 里 `"query_parser"` 改成 `"ollama"` 后重启。解析失败会自动回落规则,不会影响可用性。

## 五、企业模式（可选）

个人模式继续用上面的本地启动。若要体验企业骨架：

```bash
# 复制 deploy/secrets/*.example 为同名 .txt 并填写密钥
for f in deploy/secrets/*.example; do cp "$f" "${f%.example}.txt"; done
# PowerShell: Get-ChildItem deploy/secrets/*.example | ForEach-Object {

docker compose up -d --build
curl http://127.0.0.1:8626/readyz
```

企业模式使用 PostgreSQL/pgvector、Redis、Celery、MinIO；
不替代个人模式的本地相册工作流。细节见 `docs/企业级改造说明.md`。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 启动报缺包 | 看报错里的包名,对照上面第二步补装 |
| 索引很慢 | 用 `scripts\benchmark.py` 在本机记录真实吞吐；不要引用未经实测的耗时 |
| 搜不到语义 | 设置页看"模型后端"是否是 demo,是则装 torch+transformers |
| 想搬家/重置 | 整个程序目录 + `data/` 拷走即可;删 `data/` 等于重置 |
| 仓库里有旧密钥？ | 历史已清理；本机旧 `data/secret.key` / 密码文件请自行轮换 |
