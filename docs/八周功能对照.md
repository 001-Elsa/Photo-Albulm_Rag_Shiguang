## 企业工程增量（可单独写进简历）

- PostgreSQL/pgvector + RLS + Collection ACL
- Celery/Redis/MinIO 异步索引骨架
- 独立 Migration 进程与应用账号权限分离
- Explainable Reranker + 训练脚本（默认仍是人工权重）
- Prometheus / Grafana / OpenTelemetry 基线

## 你接下来要亲手做的三件事

1. **跑真实索引**：装好模型，索引自己的相册
2. **标注测试集**：`python eval/build_testset.py --sample 30`，补全 expected_paths
3. **留下对比结果**：`run_eval.py --tag baseline/v2 --compare`，以及 Locust / pgvector benchmark 报告

没有这三步，就不要在简历里写具体 Recall、P95 或“十万级”。
