## 你接下来要亲手做的三件事(简历数字的来源)

1. **跑真实索引**:按安装指南装好模型,把自己的相册目录索引完
2. **标注测试集**:`python eval/build_testset.py --sample 30` 抽样出题,填 100 条
   → `run_eval.py --tag baseline` 得到第一版 Recall@5/MRR
3. **做一轮优化并留痕**:调 RRF 权重 / 换模型 / 加 OCR → `--tag v2` → `--compare baseline v2`
   量化提升写进简历;`benchmark.py` 跑 fp32 vs int8 得到性能对比

> 面试官问"你的 86% 怎么来的",这三步就是答案——有测试集、有存档、有对比脚本,
> 这比数字本身更重要。
